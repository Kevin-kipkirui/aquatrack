AquaTrack icon pack
===================
1. Copy every file in this folder (except README.txt and head-snippet.html) into your project's /public folder.
2. Open index.html and replace the existing favicon <link> lines with the contents of head-snippet.html.
3. Delete public/favicon.svg if it exists (it is the file causing the 404).

logo-mark.png is the droplet on a transparent background (1024px tall) for use inside the app.
